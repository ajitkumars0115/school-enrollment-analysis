# 📊 School Enrollment Analytics & Power BI Dashboard

## 📌 Project Overview
This project provides an end-to-end data analysis of district-level school enrollments. The dataset was cleaned and anonymized using Python (Pandas), loaded into Microsoft SQL Server for detailed analytical querying, and visualized using Power BI Desktop to uncover enrollment patterns across different administrative blocks and school levels.

---

## 🛠️ Tech Stack & Tools
- **Python (Pandas):** Data cleaning, missing value imputation, and anonymization of sensitive institutional names.
- **SQL Server:** Data aggregation, grouping, and analytical queries.
- **Power BI:** Data modeling, DAX measures, and interactive KPI dashboard design.

---

## Project Files
* `clean_data.py` - Python script for cleaning and anonymizing data
* `queries.sql` - SQL queries for data analysis
* `dashboard.pbix` - Power BI dashboard file
* `enrollment_clean.csv` - Cleaned dataset
* `preview.png` - Dashboard screenshot
